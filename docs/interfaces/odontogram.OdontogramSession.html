    Interface OdontogramSession

    A host's handle on ONE odontogram's clinical state.

    Obtain one with createOdontogramSession and pass it to <OdontogramShell session={...} />, or read the process-wide standalone state with getDefaultOdontogramSession.

      Write this session's document through an injected write target. Delegates to planGuardedSave (the write plan, checked against the store through target.search so it never overwrites or deletes a resource the chart did not produce) + executeWritePlan. Throws SaveReservationsUnknownError before any write when the target cannot search and the document carries no reservations from a live load.
